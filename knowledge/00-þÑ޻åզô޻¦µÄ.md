# 知识库使用说明

这个目录是问答系统「经验库」的**人工维护**部分：纯 Markdown，一个 `##` 小节就是一条可检索的文档。

## 怎么加一条

在任意 `.md` 里加一节：

```md
## 小节标题（检索命中后显示为文档标题）

正文。写你实际踩过的坑、核实过的事实、平台规则。
```

然后重建索引：

```bash
python tools/build_rag_index.py
```

## 写什么、不写什么

| 适合写 | 不适合写 |
|---|---|
| 饰品常识（磨损、纪念品、暗金、箱子机制） | 具体价格、「现在多少钱」 |
| 平台规则（费率、T+7、提现） | 当前持仓与盈亏 |
| 指标口径（系统怎么算位置百分位、信心度） | 每日行情数字 |
| 排障经验（限流、快照过期、记账漏了） | 未核实的猜测（宁可写「待核实」） |

原因：价格与持仓是**结构化事实**，必须由 `cs2analyst/chat/tools.py` 的取数工具实时提供。
把它们写进检索库，模型就可能"从片段里捞一个过期数字当真"，这是本项目最想避免的幻觉。
